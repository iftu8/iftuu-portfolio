**TOKYO 2030** is a premium, highly optimized frontend web application designed to deliver an infinite stream of ultra-high-resolution images. Built with a cyberpunk aesthetic and Pinterest-style masonry layout, it guarantees a unique viewing experience with zero duplicate visuals.

---

## ✨ Premium Features

*   **♾️ Infinite Masonry Scroll:** A flawless, Pinterest-style dynamic grid layout that perfectly scales high-resolution images without breaking aspect ratios.
*   **🎯 Zero-Duplicate Algorithm:** Custom UUID-based seed generation ensures every single visual asset fetched is 100% unique. No repetitions.
*   **🎥 4K & 8K Ultra HD Downloads:** Users can preview images in a sleek glassmorphism modal and download native 4K or 8K assets completely free.
*   **⚡ Blazing Fast Performance:** GPU-accelerated animations, lazy loading (`decoding="async"`), and Intersection Observer API for heavily optimized infinite scrolling.
*   **🎨 Futuristic UI/UX:** Cyberpunk-inspired "Neon Tokyo" color palette featuring deep blacks, neon pinks, and cyan glows with premium typography (Outfit & Inter fonts).

---

## 🛠️ Architecture & Tech Stack

*   **Core:** HTML5, Vanilla JavaScript (ES6+)
*   **Styling:** Tailwind CSS (via CDN with custom theme extensions)
*   **Deployment & Hosting:** Vercel (CI/CD Automated)
*   **Assets API:** Lorem Picsum (Dynamic Seed Engine)

## 🚀 Quick Start & Deployment

This project is built to be serverless and heavily optimized for instant deployment. 

1. Fork or Clone this repository.
2. Connect the repository to your **Vercel** dashboard.
3. Keep the build settings to default (No framework preset required).
4. Click **Deploy**. Vercel will automatically build and assign a live production URL.
